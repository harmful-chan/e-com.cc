### 14. Glossary
The nouns used in these privacy protection guidelines have the following definitions in the general sense:
1. Personal Information: Personal information refers to various types of information that can identify the personal identity of a natural person, either alone or in combination with other information, recorded in electronic or other forms, including but not limited to the name, date of birth, identity document number, personal biometric information, address, telephone number, etc. of a natural person.
2. Sensitive Personal Information: Sensitive personal information refers to personal information that, once leaked, illegally provided, or misused, may endanger personal and property safety and is highly likely to cause damage to personal reputation, physical and mental health, or discriminatory treatment. For example, sensitive personal information includes identity document numbers, personal biometric information, bank account numbers, communication content, health and physiological information, etc.
3. Device: A device refers to a device that can be used to access E-Com products and/or services, such as a desktop computer, laptop computer, tablet computer, or smartphone.
4. Unique Device Identifier: The unique device identifier (exclusive ID or UUID) refers to a string of characters programmed into the device by the device manufacturer and can be used to uniquely identify the corresponding device (such as the IMEI number of a mobile phone). The unique device identifier has various uses, and among them, it can be used to provide advertisements when Cookie cannot be used (such as in mobile applications).
5. IP Address: Each device connected to the Internet is assigned a number, called the Internet Protocol (IP) address. These numbers are usually assigned according to the geographical region. The IP address is usually used to identify the location where the device is connected to the Internet.
6. SSL: SSL (Secure Socket Layer), also known as the secure socket layer, is a security protocol implemented on the transmission communication protocol (TCP/IP). SSL supports various types of networks and provides three basic security services, all of which achieve the effect of information confidentiality by using public key and symmetric key technologies.
7. Information Collection Technologies: The "automatic collection" mentioned in the "Privacy Protection Guidelines" of our website includes the following methods: A. Cookie Cookie is a small text file placed by the website server on the client (inside your computer, mobile phone, or other intelligent terminal) when you browse a webpage. When you visit the corresponding website again, the website can identify your browser through Cookie. Cookie may store user preferences and other information. You can configure your browser to reject all Cookies or display a prompt when the website sends a Cookie. However, without Cookie, some website functions or services may not work properly. B. Web beacon (web beacon) Web beacon is an electronic image file or other technology embedded in a website or email and can be used to count the number of visitors, record whether and when you read an email or visit a website, or be used to use certain Cookies. C. Log files (log files) Log files store certain automatically collected data. This data includes the Internet Protocol (IP) address, browser type, Internet service provider (ISP), referring/exit pages, operating system, date/time stamp, and clickstream data, etc. D. ET Tag (entity tag) ET Tag is an HTTP protocol header transmitted behind the scenes between the Internet browser and the Internet server and can replace Cookie to track individual users, enabling our website to better understand and improve our services. E. JavaScript JavaScript is a programming language used to create more interactive and dynamic web pages. JavaScript can set, read, and delete Cookies.
8. Affiliated Company: An affiliated company refers to any company or institution that is currently or will be controlled by, controlling, or under the common control of a certain party. "Control" means directly or indirectly having the ability to influence the management of the mentioned company, whether through ownership, voting shares, contracts, or other legally recognized means.
9. Algorithm: The process or a series of rules followed by a computer when performing problem-solving operations.
10. Application Data Cache: Application data cache refers to a data storage mechanism on a device. Using it has many benefits, such as allowing network applications to run without an Internet connection and improving the performance of related applications by increasing content loading speed.
11. Using Browser for Network Storage: The mechanism of "using browser for network storage" allows a website to store data in the browser on the device. If this mechanism is used in the "local storage" mode, the data can be stored across sessions. In this way, even after closing and reopening the browser, the user can still access the corresponding data. One of the technologies that helps achieve network storage is HTML 5.
12. Account: As long as you register an account and provide some personal information to our website (as described in Section 3.1 of these Guidelines), you can use our website's services. When you visit E-Com, the system will use this account information to authenticate you to prevent unauthorized access to your account.
13. Non-Personal Identification Information: Information related to the user that is actually unable to directly or indirectly identify your identity, including personal information provided through de-identification, anonymization, or pseudonymization.
14. De-identification: The process of making personal information unable to identify the personal information subject without the help of additional information through technical processing of personal information.
